# Game references and visual direction

The project uses real-time 3D, NASA's rover asset, and original environments and
writing. These references guide design principles; they are not asset sources.

| Reference | Principle to explore in Last Light |
| --- | --- |
| [Journey — thatgamecompany](https://thatgamecompany.com/journey/) | A small figure against a vast landscape; distance, light, and restrained music can make solitude feel beautiful before it feels painful. |
| [Outer Wilds — Mobius Digital](https://www.mobiusdigitalgames.com/outer-wilds.html) | Let curiosity and observations create attachment. A new understanding of a place can be a reward in itself. |
| [The Invincible — Starward Industries / 11 bit studios](https://11bitstudios.com/games/the-invincible/) | Make scientific tools and machinery feel tangible within an unfamiliar landscape. Let instruments carry the storytelling. |

These are our design interpretations of the official descriptions, not claims
that the games use identical mechanics. No models, textures, music, dialogue,
characters, layouts, or code from these games are included.

For this build: readable rover silhouette, low horizons, tactile instrument views,
slow observation, warm early light, and gradually obscured distance. The real NASA
model supplies mechanical detail; procedural terrain supplies an original stage.
The landscape is an interpretation of Mars, not a surveyed reconstruction of
Opportunity's route. Keep the rover model visible and useful to interaction so
that the experience is more than text placed over a rotating object.

The cover and graphics-failure fallback use the actual-game render in
`public/images/last-light-hero.webp`. The earlier generated poster was removed
in v0.19.8; [ART.md](ART.md) retains its historical provenance. Current credits
and asset sources live in [SOURCES.md](SOURCES.md), [BIBLIOGRAPHY.md](BIBLIOGRAPHY.md)
and [ASSETS.csv](../public/ASSETS.csv).
