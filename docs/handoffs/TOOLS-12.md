# TOOLS-12 — controlled geological tools

Scope: `src/ui/landscape.js`, `src/engine/geology-tool.js`, `tests/engine/geology-tool.test.js`.

Implemented a deterministic tool interaction for `stone-ripples` and `blueberries`. Right-stick axes move a bounded probe over an authored local 3D surface. Holding R2 removes only dust cells under the head; stationary holding saturates a small footprint and cannot finish. At 56% coverage, release R2 before obtaining two distinct 0.7-second readings at visible rings. Read rings turn green. Explicit comparison completes the interaction; neither a held trigger nor elapsed time compares automatically. Last Chance compares crossing layer orientations; Berry Bowl compares authored qualitative relative iron-bearing signals, never numerical telemetry.

API: `setToolMode(sceneId|null)` returns active boolean, preserving progress for repeated same-ID calls. `setToolInput({x,y,pressure,measure})`; `compareToolSamples()` returns success boolean. `tool-sample` bubbles approximately every 100ms and immediately on start/compare: `{stage,progress,coverage,requiredCoverage,samples,targets,target,cursor,hint,complete,operating,toolMotion}`. Target/cursor coordinates are normalized local surface coordinates. Pointer down/drag maps directly onto the rock plane and operates the tool. Pointer release, blur, visibility loss and pause stop pressure and require an observed release before operating again. Entry also requires neutral input, so R2 carried from driving cannot brush. Pointer dragging retains pressure despite neutral external controller polls. Null mode clears progress. Existing camera, driving and survey APIs remain.

Visual implementation uses a 576-instance conforming powder grid with feathered procedural grain alpha and face-aligned normals, one head and two target rings. Last Chance dust chips and probe are raycast onto its actual front mesh, avoiding embedded dust on the uneven layered cap. Dedicated macro view hides the rover, preventing deck occlusion; the smaller probe retains visible stone around its nose. Only a matching active tool-pointer release stops pointer operation, so unrelated UI clicks cannot cancel gamepad pressure. Resizing retains tool framing. No dependencies, imported assets or physical controller output added.

Checks actually run: Node syntax check on landscape; 5 engine tests pass (spatial coverage versus idle, distinct measurements/release/explicit compare, pause/invalid-input bounds). Browser QA and complete playthrough are not claimed; integrator/critic must verify final controls, camera framing and soundtrack together.

Known boundary: interaction is an authored teaching reconstruction, not a replica of flight instrument acquisition or an element abundance measurement. Dust coverage threshold is a gameplay criterion. Input must be supplied continuously by the integrator, including neutral values on release.
