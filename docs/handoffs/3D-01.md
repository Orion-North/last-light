# 3D-01 — navigable Martian environment

- Owner: Codex systems subagent.
- Allowed/changed paths: `src/ui/landscape.js`, this handoff.
- Uses the parent-vendored Three.js 0.180.0 import map (`three`, `three/addons/`).
- Loads the parent's official NASA textured Opportunity asset from
  `public/models/opportunity.glb`; no Draco or remote runtime requests required.

## Delivered

Real WebGL terrain with smooth procedural height, vertex colors and granular
surface texture; instanced eroded rocks/pebbles; a layered outcrop; atmospheric
sky and directional sun; fog, dust, shadows and environment reflections.
The NASA model is normalized, grounded and tilted to the local terrain. Orbit,
zoom, bounded drive motion, collision avoidance, and persistent tire tracks are
implemented. No model substitute is shown or reported as ready if loading fails.

All original methods remain. Added methods:

- `setMode('title' | 'game' | 'ending')`: idempotent, disables driving outside game.
- `setDrive({ forward, turn })`: values in [-1, 1]; manual input cancels assistance.
- `focusRover()` and `inspect()`: smooth framing, immediate under reduced motion.
- `setWaypoint({ x, z, label })` or `setWaypoint(null)`: sets a terrain marker;
  goals outside 17 m are clamped inside the drive area.
- `travelToWaypoint()`: returns boolean, computes a rock-avoiding grid route and
  physically steers the rover. Manual drive cancels; arrival ends assistance.

Events dispatched from canvas and bubbled:

- `world-status`: `{ state: 'loading' | 'ready' | 'error', message }`.
- `rover-move` and compatibility `world-drive`: `{ x, z, distance, blocked, remaining }`.
  `distance` is cumulative driving; `remaining` is distance to current marker.
- `waypoint-reached`: `{ x, z, label, distance }`, within 1.7 m of goal.
- `navigation-status`: blocked route explanation if assisted navigation fails.

The parent is the sole keyboard/touch movement controller. The module contains
no keyboard event handlers. Signal/power zero also disables driving internally.
Pause disables orbit and progression; reduced motion stops dust and camera easing
but preserves user-controlled exploration. Pixel ratio caps at 1.5.

## Validation and limitations

`node --check src/ui/landscape.js` and `git diff --check` passed. Parent browser QA
confirmed the NASA GLB renders and imports succeed. Parent's first visual review
prompted smoother rock normals, fewer nearby large rocks, a closer/lower camera,
lower sun, restrained exposure, and terrain sampling for initial wheel contact.
Those refinements need the parent's next browser pass. Assisted routes and all
six authored waypoints still need end-to-end browser verification.

Terrain/placement and traversal are an artistic reconstruction, not a survey map
or rover engineering simulator. Loading is the real asset, not imagery. Physical
wheel spinning and suspension articulation are not implemented because the NASA
GLB is static combined mesh geometry. Initial download exceeds the earlier 10 MB
target because the real textured rover alone is ~11.9 MB.
