# GLYPHS-04 / integration

Codex owns original vector PlayStation/Xbox/generic prompts and the family override,
controller-first main flow, centered cinematic captions, per-phase objective,
investigation accumulation, and contact interaction. No vendor glyph assets copied.

Connected standard controllers drive only in traversal; menus receive the left
stick; investigation/contact receive the right stick. Square opens the optional
journal, Triangle resets the current view, Options pauses. Explicit assistance is
never chosen implicitly by an unfocused primary button. Device loss pauses play.
Touch/keyboard use the same scene/state flow. Optional USB touch is aim-only;
release/disconnect cannot commit Send. A focused non-send action remains honored.

Tests and checks: prompt-family tests, input-mode and investigation tests, all
engine test files and source contracts passed. Browser confirmed both geological
investigations and the active send sequence. Physical controller/iPad feel and
sound balance still require device playtest. Published v0.3 was not replaced.
